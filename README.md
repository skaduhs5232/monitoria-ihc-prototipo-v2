Este repositório tem duas versões:

1. **`/baseline-corrigido/` – versão usada no teste com usuários (Etapa 1.5).** São as telas originais em imagem, com uma única correção indispensável no invólucro: o problema C-01 (E1-02/E1-16, botões de ação da tela Alunos e "Ver explicação completa"). Os demais problemas foram mantidos, porque o enunciado pede para preservar o Baseline e documentar a versão corrigida separadamente.
2. **Raiz (`/`) – versão v2.** Refaz as telas em HTML/CSS/JS reais e corrige também E1-01, E1-03 a E1-09 e E1-11 a E1-15. As instruções usadas para construí-la estão em `PROMPTS.md`.

Os dados são fictícios. Para usar, basta abrir `index.html`; não há build.
